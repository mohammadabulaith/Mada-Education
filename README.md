# 🎓 منصة مدى التعليمية | MADA Educational Platform

### رياضيات بلا حدود... تعلّم، تفاعل، إبداع

منصة تعليمية تفاعلية باللغة العربية، تستهدف طلبة الصفوف الأساسية من الأول إلى الرابع، وتهدف إلى تقديم تجربة تعلم ممتعة باستخدام الأدوات الرقمية ومصادر التعلم المفتوحة (OER).

## 🌟 أهداف المنصة
- تعزيز التعلم التفاعلي لدى الطلبة.
- دعم المعلمين بأدوات وأنشطة تعليمية رقمية.
- توفير بيئة تعليمية مشوقة ومناسبة للصفوف الأولية.
- دعم تطوير المحتوى التعليمي بصورة مستمرة.

## 📚 الفئات المستهدفة
- طلبة الصفوف الأساسية من الأول إلى الرابع.
- المعلمون والمعلمات.
- أولياء الأمور.
